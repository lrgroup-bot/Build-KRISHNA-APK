# Graph Intelligence
Use dependency-aware message passing to rank components relevant to an incident,
goal or question. Scores are advisory evidence only and never authorize repair.
Verified incidents may later become supervised training examples for an optional
local relational GNN. Keep deterministic fallback available when ML packages are absent.
