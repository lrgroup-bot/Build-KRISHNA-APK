# KRISHNA Completion Matrix
PR #22 consolidates the production boundaries for the remaining roadmap.

## Implemented runtime boundaries
- Verified-only completion event gate
- Verified-only graph/GNN dataset
- Remote paired-device + explicit capability authorization
- Local CLI voice-provider adapter
- Rigged GLB manifest/validation boundary
- Existing graph intelligence + optional PyG backend
- Existing bounded Ruflo adapter + worker supervisor
- Existing durable mobile resume/idempotency
- Existing shadow repair + verification
- Existing Windows EXE workflow

## Environment-dependent completion
The repository cannot manufacture external prerequisites. A trained GNN requires verified examples and a local ML environment. Voice requires an installed local STT/TTS executable/model. A rigged avatar requires an actual rigged GLB asset with animations/morph targets. Remote internet operation requires a user-controlled private network/VPN or equivalent secure route. These are detected/configured at runtime and must not be falsely reported as installed.
